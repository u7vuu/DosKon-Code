# DoseKon — ماذا تغيّر في هذا الإصدار

## الفكرة
بيانات الأدوية (الأسماء، الجرعات، المعادلات، معلومات الحقن) لم تعد مكتوبة داخل
`index.html`. أصبحت في ملف منفصل:

```
assets/appdata.json
```

المتصفح يجيبه بطلب شبكة منفصل بعد تحميل الصفحة، فـ "View Source" لصفحة
index.html لم يعد يُظهر أي بيانات جرعات أو أدوية — فقط هيكل الواجهة الفارغ.
هذا يرفع الجهد المطلوب لنسخ التطبيق كاملًا بخطوة واحدة، مع بقاء التطبيق **يعمل
أوفلاين بالكامل** كما كان (راجع قسم "لماذا هذا الحل" بالأسفل).

## كيف تضيف دواء جديد (سهل، بدون لمس HTML)
1. افتح `assets/appdata.json`.
2. اختر المجموعة (grid) المناسبة حسب نوع الدواء:
   - `grid-penicillins`
   - `grid-cephalosporins`
   - `grid-macrolides`
   - `grid-other`
   - `grid-injection`
3. أضف عنصر جديد (object) داخل المصفوفة المناسبة.

### مثال: دواء شراب (syrup) جديد
```json
{
  "type": "syrup",
  "name_html": "اسم الدواء",
  "generic": "الاسم التجاري (اختياري)",
  "chip": "Penicillin",
  "dose_line_html": "<b>40 mg/kg/day</b> divided q8hr",
  "concentrations": [
    { "factor": 0.5, "freq": 3, "label_html": "125 mg / 5 mL", "freq_tag": "×3/day" }
  ]
}
```

### مثال: دواء حقن (injection) جديد
```json
{
  "type": "injection",
  "name_html": "اسم الدواء",
  "chip": "Vial",
  "dose_line_html": "<b>50 mg/kg/dose</b>, q8hr",
  "strengthChips": ["1 g"],
  "routes": [
    { "badge": "IV", "badge_class": "iv", "text": "1 g in 10 mL WFI — IV direct" }
  ],
  "adminNote_html": "<b>Compatible with:</b> NaCl 0.9%"
}
```
لو الدواء له أكثر من تركيز/فيال، استخدم `vialGroups` بدل `routes` (زي باقي
أدوية الحقن الموجودة في الملف — انسخ أقرب مثال شبيه وعدّل عليه، أسهل من كتابته
من الصفر).

بعد الحفظ، ادفع (push) الملفات زي ما تعمل عادةً — مفيش خطوة بناء (build) إضافية.

## لماذا هذا الحل بالذات (ملخص القرار اللي اتفقنا عليه)
كان فيه مفاضلة: حجب بيانات الجرعات بالكامل عن طريق نقلها لسيرفر خارجي كان
سيمنع التطبيق من الحساب أوفلاين. اخترنا الحل المتوسط:
- البيانات تُجلب من ملف JSON منفصل (مش داخل HTML) → صعّب النسخ بخطوة واحدة.
- الملف يُخزَّن في ذاكرة التخزين المؤقت (Service Worker) بعد أول تحميل ناجح
  → التطبيق يفضل يشتغل أوفلاين بالكامل زي الأول.
- عند التحديث (push لملف appdata.json)، أي مستخدم متصل بالإنترنت يجيب
  النسخة الأحدث فورًا (network-first)، من غير ما ينتظر تحديث كامل للتطبيق.

## ملاحظة تقنية
- الملف `index.html` بيعمل `fetch('./assets/appdata.json')` عند التحميل ويبني
  كل الكروت بـ JavaScript.
- الـ Service Worker (`service-worker.js`) بيفرّق بين نوعين من الكاش:
  - هيكل التطبيق (HTML/CSS/JS) → cache-first (سريع، وأولوية للنسخة المحفوظة).
  - `assets/appdata.json` → network-first (أولوية للإنترنت، مع fallback
    للنسخة المحفوظة لو مفيش نت).
